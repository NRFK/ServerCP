CONNECT SERVERCP

Access your panel through a tunnel

Create a tunnel in Cloudflare, install cloudflared on the panel host, then run the included helper:

sudo bash /opt/servercp/install-tunnel.sh

Set the tunnel’s public route to http://127.0.0.1:8090. The helper keeps the token in a protected file and enables a connector service.

Remote server administration still requires SSH connectivity from the panel host, directly or through a private network route.

SECURE SSH CONNECTION

Add a server

Add the panel’s own host or any remote Ubuntu/Debian machine.

Verify on the server console: ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub -E sha256

Credentials are encrypted on the panel host. The fingerprint must match before a connection is allowed.
